Horse Watch

          
Daily Racing Form · Company project: Haptiq

          

            

              
Problem

              
DRF runs many small apps under one umbrella (SSTF, single site top of funnel) and wanted
                one widget across all of them.

            

            

              
Decision

              
A loader plus widget manager, injected into every app through GTM.

            

            

              
Rejected

              
Installing a package in each host app, which forced a production deployment of every app
                per change.

            

            

              
Delivery

              
Versioned loader files in S3, a copy in /latest, and GTM loads
                /latest.
              

            

            

              
Isolation

              
Shadow DOM with HW-* prefixed ids and classes.

            

            

              
Real-time

              
Leader election (Web Locks API + BroadcastChannel) shares one SSE connection across
                tabs, cutting backend connections from O(n) to O(1).

            

            

              
Outcome

              
Live at drf.com. ~70K of ~100K monthly users opened the widget in month one.

            

            

              
Trade-off

              
GTM injection adds a runtime dependency on the tag manager. Ad-blocker impact is
                unmeasured.

            

            

              
Stack

              
Shadow DOM, GTM, S3, SSE, Web Locks API, BroadcastChannel

NeuraLens

          
Self-directed project

          

            

              
Goal

              
Learn LLM integration in React Native.

            

            

              
What it does

              
Capture or upload an image and get a structured analysis (overview, key objects,
                context) plus an explicit-content flag.

            

            

              
Decision

              
A structured prompt (Role, Task, Context, Rules, Reasoning, Stop condition, Output)
                returning strict JSON with an explicitContent field.

            

            

              
Trade-off

              
Prompt-based flagging means the same model analyzes and polices the image. A production
                system would add a dedicated moderation service.

            

            

              
Stack

              
React Native (Expo), NestJS, MongoDB, S3 pre-signed uploads, Llama 4 Maverick via
                OpenRouter

            

          

        

      

      
        

          
          
RAG Pipeline Visualizer

          
Self-directed project

          

            

              
Stages exposed

              
Query embedding, retrieval with similarity scores, prompt construction, answer
                generation.

            

            

              
Finding

              
"Can I use Express behind nginx?" failed. The docs say "reverse proxy", so retrieval
                missed content that was in the corpus. The similarity threshold stopped the request
                instead of letting the LLM answer confidently.

            

            

              
Eval

              
Recall@3 harness comparing fixed-size and structure-aware chunking. Results so far are
                inconclusive.

            

            

              
Next

              
Hybrid search (BM25), re-ranking, MRR.

            

            

              
Stack

              
Node/Express, React, transformers.js (all-MiniLM-L6-v2), JSON vector store with cosine
                similarity, OpenRouter

            

          

        

      

      
        

          
          
Newbie Horse Racing

          
Daily Racing Form · Company project: Haptiq

          

            

              
Problem

              
DRF's core audience skews older, and younger people were less drawn to horse racing. DRF
                needed a way to reach them.

            

            

              
Role

              
Architect and hands-on engineer, designing the system with the tech manager and writing
                code.

            

            

              
Decision

              
Launch Newbie as a separate satellite product instead of redesigning the core site. It
                carries the same racing data and information with a simpler, friendlier UI/UX for Gen Z
                and first-timers.

            

            

              
Funnel

              
Newbie prompts sign-up and routes the traffic it attracts into core DRF, so it works as
                a top-of-funnel product.

            

            

              
Outcome

              
Almost 10K new users signed up through Newbie during the Breeders' Cup event (Oct–Nov
                2025).

            

            

              
Stack

              
Preact frontend, Node.js backend-for-frontend (BFF)

            

            

              
Status

              
Live at newbie.drf.com.
